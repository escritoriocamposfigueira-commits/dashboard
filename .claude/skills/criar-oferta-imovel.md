# /criar-oferta-imovel — Oferta de Imóvel Completa

## Componentes da Oferta
1. **Título** (max 80 chars): bairro + tipo + diferencial principal
2. **Subtítulo**: faixa de valor + condição de pagamento
3. **Descrição emocional** (2-3 parágrafos): lifestyle, benefícios, localização
4. **Ficha técnica**: área, quartos, banheiros, vagas, andar, condomínio
5. **Localização**: bairro + cidade + pontos de referência
6. **Condições**: aceita financiamento? FGTS? permuta? direto proprietário?
7. **Referência**: código interno (REF: XXX)
8. **Contato**: (11) 2378-5643 | CRECI: 043649-J | @escritorio.figueira
9. **Fotos necessárias**: lista de ambientes a fotografar

## Checklist de Lançamento
☐ Fotos profissionais de todos os ambientes
☐ Foto aérea (drone) se disponível
☐ Planta baixa digitalizada
☐ Documentação verificada
☐ Preço confirmado com proprietário
☐ Condições de pagamento confirmadas
☐ Aprovado para publicação
