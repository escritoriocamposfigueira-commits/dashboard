# /criar-copy-anuncio-imovel — Copy de Anúncio Imobiliário

## Objetivo
Criar textos que convertem — baseados em características REAIS do imóvel,
emoção genuína e CTA direto para WhatsApp.

## Estrutura Obrigatória (AIDA adaptada para imóveis)

```
1. GANCHO (1-2 linhas) — dor, medo ou desejo do comprador/locatário
2. PONTE (1-2 linhas) — como este imóvel resolve o problema
3. BENEFÍCIOS (lista ✅) — características reais, sem inventar
4. PROVA / ÂNCORA (opcional) — preço, financiamento, referência
5. URGÊNCIA REAL (só se houver) — nunca inventar escassez
6. CTA DIRETO — palavra-chave + WhatsApp
```

## Personas e Ganchos

**Comprador primeira casa:**
"Você cansa de pagar aluguel e o imóvel nunca ser seu?"

**Família que cresceu:**
"Seus filhos merecem ter um quarto só deles."

**Investidor:**
"E se o seu imóvel pagasse as contas por você todo mês?"

**Locatário qualidade:**
"Chega de morar em lugar que não cabe sua vida."

**Comercial/Empresário:**
"Seu negócio merece um endereço à altura."

## Regras
- Nunca inventar preço, condição ou característica
- Nunca prometer aprovação de financiamento
- Nunca usar urgência falsa ("última unidade" sem confirmar)
- Sempre incluir CRECI: 043649-J
- Sempre incluir @escritorio.figueira

## Formatos por plataforma

**Instagram/Facebook (caption):** até 2.200 caracteres, emojis moderados
**WhatsApp (mensagem):** máximo 300 palavras, direto
**Google/Portal:** título 60 chars + descrição 150 chars

## Exemplos de Uso
1. "cria copy para o sobrado 3 quartos R$ 490k Jundiapeba" → texto completo
2. "legenda Instagram para casa com piscina Morumbi" → caption otimizado
3. "mensagem WhatsApp para locação comercial" → copy direto

## Limitações
- Não cria copy sem informações reais do imóvel
- Não usa dados não confirmados pelo usuário
