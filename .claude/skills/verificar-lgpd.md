# /verificar-lgpd — Conformidade LGPD

## Bases Legais para Dados Imobiliários
- **Consentimento**: formulário Lead Ads com aviso de privacidade
- **Execução de contrato**: dados necessários para fechar negócio
- **Legítimo interesse**: follow-up de leads que demonstraram interesse

## O Que Deve Estar Claro para o Lead
1. Quais dados são coletados (nome, telefone, interesse)
2. Para que serão usados (contato do corretor)
3. Por quanto tempo serão mantidos
4. Como solicitar exclusão: (11) 2378-5643

## Boas Práticas no Formulário Meta
- Incluir link para Política de Privacidade
- Texto: "Seus dados serão usados apenas para contato sobre imóveis"
- Não solicitar dados desnecessários (CPF, RG só no fechamento)

## Direitos do Titular
O lead pode a qualquer momento:
- Saber quais dados temos
- Corrigir dados incorretos
- Solicitar exclusão
- Revogar consentimento
