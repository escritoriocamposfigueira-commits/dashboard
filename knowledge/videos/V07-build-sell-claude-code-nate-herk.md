## Resumo Técnico

Nate Herk, criador da AI Automation Society (comunidade no Skool), lançou em março de 2026 este curso gratuito de mais de 10 horas que cobre tudo desde setup até como encontrar clientes e precificar serviços com Claude Code. O curso é notável por uma característica incomum: você não escreve nenhuma linha de código durante todo o treinamento.

Nate vem de um background de automação no-code (ele também tem um curso de 8 horas de n8n com mais de 500 mil dólares em receita em 8 meses), e traz essa perspectiva de negócio para o Claude Code. A proposta é que Claude Code torna o "no-code" ainda mais acessível — você descreve o que quer em linguagem natural e o Claude Code constrói.

O curso foi desenvolvido ao longo de semanas e cobre: setup completo, construção de fluxos de trabalho automatizados, deploy de websites, criação de agent teams, automação de browser, como encontrar clientes e como precificar o trabalho. É essencialmente um curso de negócio de automação com Claude Code como ferramenta central.

A filosofia do Nate é que em 2026, a habilidade escassa não é programação — é saber identificar problemas de negócio que podem ser resolvidos com IA e ter a capacidade de implementar a solução. Claude Code nivela o campo ao remover a barreira técnica de programação.

O formato do curso inclui demos ao vivo de projetos reais, templates reutilizáveis compartilhados na comunidade, e suporte via a comunidade AI Automation Society no Skool.

## Procedimento / Conceitos Principais

1. **Setup sem código do início ao fim**:
   - Instalar Node.js e Claude Code sem digitar código manualmente
   - Usar Claude Code para configurar o próprio ambiente de desenvolvimento
   - Primeiro projeto: pedir ao Claude Code para criar uma pasta organizada e um README

2. **Fluxos de trabalho automatizados**:
   - Identificar tarefas repetitivas no negócio do cliente
   - Descrever o fluxo em linguagem natural para o Claude
   - Claude Code gera scripts, configura automações e testa
   - Validar resultado manualmente antes de deixar rodando autonomamente

3. **Deploy de websites completos**:
   - Descrever o site desejado: "quero um site de landing page para uma agência de imóveis"
   - Claude Code gera HTML/CSS/JS ou Next.js completo
   - Deploy automático via Vercel ou Netlify com comando único
   - Customizar iterativamente via linguagem natural

4. **Agent teams práticos (sem código)**:
   - Definir papéis em linguagem natural: "quero um agente de pesquisa e um de escrita"
   - Configurar coordenação via CLAUDE.md e arquivos de agentes
   - Monitorar progresso em tempo real via interface do Claude Code
   - Coletar e revisar resultados finais

5. **Automação de browser**:
   - Claude Code com ferramentas de browser automation (Playwright via MCP)
   - Raspar dados de sites concorrentes para análise competitiva
   - Preencher formulários e fazer submissões automaticamente
   - Gerar screenshots e relatórios visuais

6. **Encontrar clientes — estratégias práticas**:
   - Nicho-down: focar em um setor específico (ex: imobiliário, advocacia, contabilidade)
   - LinkedIn: demonstrações de automações relevantes para o nicho
   - Cold outreach: e-mail com problema específico do destinatário + solução proposta
   - Referências: pedir indicações de clientes satisfeitos sistematicamente

7. **Precificação de serviços**:
   - Precificação por projeto (não por hora): estimar valor entregue, não tempo gasto
   - Projetos iniciais: R$2.000-R$8.000 para automações simples
   - Projetos complexos com agent teams: R$15.000-R$50.000
   - Manutenção mensal: 10-20% do valor do projeto inicial
   - Proposta de valor: "quanto tempo você gasta nisso por semana? Eu automatizo isso."

8. **Pacotes de entrega para clientes**:
   - MVP em 48-72 horas para validar interesse do cliente
   - Versão completa em 1-2 semanas
   - Documentação de uso para cliente não-técnico
   - Treinamento de 1 hora para o cliente operar a automação

9. **Gestão da relação com cliente**:
   - Check-in semanal nas primeiras 4 semanas após entrega
   - Monitoramento de custo de API para prevenir surpresas na fatura
   - Plano de escalonamento quando volume aumenta

10. **Construção de portfólio**:
    - Documentar 3-5 projetos com vídeo de demo + resultado mensurável
    - GitHub com código comentado (mesmo que Claude tenha escrito)
    - Case studies com métricas: "reduziu de 8 horas semanais para 30 minutos"

## Conhecimentos Úteis

- A abordagem "no-code com Claude Code" democratiza automação para empreendedores sem background técnico
- O mercado de automação B2B em PME (pequenas e médias empresas) é o mais acessível para freelancers iniciantes
- Nicho-down é fundamental: conhecer profundamente os problemas de um setor (ex: imobiliário) é mais valioso que saber Claude Code genérico
- A precificação por valor (não por hora) muda completamente a equação — uma automação que economiza R$3.000/mês de mão de obra pode ser vendida por R$10.000
- Automação de browser (Playwright) via Claude Code é uma das capacidades mais poderosas e menos exploradas — permite interagir com qualquer site como um humano
- O modelo de manutenção mensal cria receita recorrente previsível — fundamental para sustentabilidade do negócio
- A comunidade (AI Automation Society no Skool) é parte fundamental do valor — acesso a templates, projetos de outros membros e suporte peer-to-peer

## Aplicação no Campos Figueira

- **Automação de portais sem código**: Usar Claude Code para automatizar publicação e atualização de imóveis nos portais ZAP, OLX e Viva Real sem necessidade de desenvolvedor
- **Landing pages de imóveis**: Criar landing pages específicas para imóveis de destaque com descrição, fotos e formulário de contato — geradas e deployadas pelo Claude Code
- **Raspagem de mercado**: Usar automação de browser para monitorar preços de imóveis similares em Mogi das Cruzes nos portais concorrentes
- **Relatórios automáticos**: Claude Code gerando relatórios semanais de performance dos anúncios online sem intervenção manual
- **Caso de uso vendável**: O sistema desenvolvido para o Campos Figueira pode ser o portfólio para oferecer o mesmo serviço para outras agências imobiliárias de Mogi das Cruzes e região
- **Precificação local**: Adaptar as faixas de preço do curso para o mercado brasileiro e específico de Mogi das Cruzes (empresas menores, orçamentos menores)
- **Treinamento da equipe**: O formato sem código do curso é ideal para treinar corretores e assistentes administrativos a usar Claude Code para tarefas do dia a dia
